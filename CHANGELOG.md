# Changelog

Все изменения в проекте Smart Desktop.

## [v1.1.0] - 2026-05-27

### ✨ Новые возможности
- **Адаптивная ширина панели** — автоматически подстраивается под количество пространств (2-10)
- **Зеркалирование интерфейса** — полная инверсия UI при выборе позиции "Слева"
- **Три темы оформления** — Водяная, Тёмная, Светлая с мгновенным переключением
- **Real-time мониторинг окон** — автоматическое обновление списка каждые 2 секунды
- **Умное авто-закрытие** — панель закрывается через 15 сек бездействия (настраиваемо)
- **Горячие клавиши Ctrl+F1..F4** — быстрое переключение между пространствами

### 🐛 Исправления
- Исправлена ошибка `AttributeError` при инициализации тем
- Исправлено позиционирование кнопки-флажка для левой панели (теперь x=0)
- Исправлено отображение кнопок управления при смене количества пространств
- Добавлены безопасные проверки `hasattr()` для всех UI элементов

### 🎨 Улучшения UX
- Автозакрытие панели через 500мс после применения настроек
- Увеличены отступы между кнопками пространств (padx=4 вместо 2)
- Плавные alpha-анимации появления/исчезновения панели
- Ripple-эффекты при всех действиях

### ⚙️ Технические улучшения
- Асинхронное обновление списка окон (не блокирует UI)
- Кэширование GetWindowRect для производительности
- Логирование всех важных событий
- Атомарная запись конфигов с бэкапом

### 📝 Документация
- Обновлён README с описанием новых функций
- Добавлен CHANGELOG
- Улучшены комментарии в коде
