## ✨ Возможности v1.1

###  Адаптивный интерфейс
- **Адаптивная ширина** — панель автоматически расширяется под количество пространств (2-10)
- **Зеркалирование** — полная инверсия UI при выборе позиции "Слева"
- **3 темы оформления** — Водяная 💧, Тёмная 🌙, Светлая ☀️

### ⚡ Производительность
- **Real-time мониторинг** — автоматическое обновление списка окон каждые 2 сек
- **Асинхронные операции** — UI не блокируется при сканировании окон
- **Кэширование** — оптимизированные вызовы Windows API

### 🎯 Управление
- **Горячие клавиши** — F1 (меню), F2 (расставить), F3 (сохранить), Ctrl+F1..F4 (пространства)
- **Умное авто-закрытие** — через 15 сек бездействия (настраиваемо 0-60 сек)
- **Показать рабочий стол** — кнопка 🖥️ или Ctrl+D

### 💾 Сохранение
- **Сохранение позиций** — запоминает расположение каждого окна
- **Автосохранение** — конфигурация сохраняется при изменении
- **Бэкап конфигов** — автоматическое создание .bak файлов
