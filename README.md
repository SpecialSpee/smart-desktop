## ✨ Возможности

### 🎯 Управление окнами
- **Пространства (до 10)** — группируйте окна по задачам: работа, учёба, развлечения
- **Быстрое переключение** — `Ctrl+F1..F4` мгновенно меняет активное пространство
- **Сохранение позиций** — запомните идеальную расстановку и восстанавливайте её в один клик

### 🌐 Режим «Все окна» (новинка v1.2!)
- Нажмите 🌐 или `Ctrl+A` — **все открытые окна** расставятся ровной сеткой
- Автоматический расчёт оптимальной сетки под количество окон
- Начинает расстановку **с верхнего края** экрана, не перекрывая панель задач

### ⌨️ Горячие клавиши (полностью настраиваемые)
| Действие | По умолчанию | Настраивается |
|----------|-------------|---------------|
| Открыть/закрыть панель | `F1` | ✅ |
| Применить расстановку | `F2` | ✅ |
| Сохранить позиции | `F3` | ✅ |
| Показать рабочий стол | `Ctrl+D` | ✅ |
| Режим «Все окна» | `Ctrl+A` | ✅ |
| Пространство 1–4 | `Ctrl+F1..F4` | ✅ |

> 💡 Все хоткеи можно изменить в **⚙️ Настройки → ⌨️ Горячие клавиши**

### 🎨 Темы оформления
- 💧 **Водяная** (синяя) — фирменный стиль с анимированной рябью
- 🌙 **Тёмная** — для работы в условиях низкой освещённости
- ☀️ **Светлая** — классический светлый интерфейс

### ⚙️ Гибкие настройки
- Позиция панели: слева / справа
- Авто-закрытие панели после бездействия (0–60 сек)
- Задержка закрытия после применения расстановки (1–10 сек)
- Лимит окон на пространство (5–50)
- Интервал обновления списка окон (500–5000 мс)

## 🚀 Быстрый старт

### Требования
- Windows 10/11
- Python 3.11 или новее
- ~50 МБ свободного места

### Установка

```powershell
# 1. Клонируйте репозиторий
git clone https://github.com/SpecialSpee/smart-desktop.git
cd smart-desktop

# 2. Установите зависимости
python -m pip install -r requirements.txt

# 3. Запустите приложение
python desktop_manager.py
